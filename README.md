# Portfólio de Kamila Ribeiro Gomes

Site estático pronto para GitHub Pages. Arquivos: `index.html`, `styles.css`, `script.js`.

## Publicar
1. Crie um repositório público no GitHub, por exemplo `portfolio-kamila`.
2. Use **Add file > Upload files** e envie os três arquivos (`index.html`, `styles.css`, `script.js`) para a **raiz** do repositório. Clique em **Commit changes**.
3. Abra **Settings > Pages**; em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`, e salve.
5. Aguarde a publicação. O endereço geralmente será `https://SEU-USUARIO.github.io/portfolio-kamila/`.

## Antes de divulgar
- Revise cada descrição de projeto e confirme que é permitido citar os clientes e atividades.
- Acrescente links de repositórios e demonstrações apenas quando estiverem públicos e autorizados.
- Para incluir o currículo, adicione um PDF ao repositório e crie um link no `index.html`.
- Para atualizar, edite os arquivos e faça commit; o site será republicado.
- Não envie senhas, tokens, dados de clientes ou documentos internos.
